## 摘要
生成扩散模型的性能由连接经验分布与先验分布的参考扩散过程的选择决定。传统方法通常需要在无模拟训练与有限时间生成之间进行权衡。我们提出了一个设计参考过程的框架，可同时实现两者。关键思想是规定易于处理的时间相关条件分布，然后构造以这些分布为边缘分布的参考过程。该框架揭示，分数匹配并非扩散模型训练的基本要素，而是通过参考过程的逆过程自然涌现的。我们进一步证明，条件流匹配是所提框架的小噪声极限。

## Abstract
The performance of generative diffusion models is determined by the choice of the reference diffusion process connecting the empirical and prior distributions. Conventional approaches typically trade off simulation-free training against finite-time generation. We propose a framework for designing the reference process that achieves both simultaneously. The key idea is to prescribe tractable time-dependent conditional distributions and then construct the reference process realizing them as its marginals. This framework reveals that score matching is not fundamental to diffusion-model training but instead emerges naturally through reversal of the reference process. We further show that conditional flow matching arises as the small-noise limit of the proposed framework.

## 2. 论文提出的方法论

### 2.1 核心思想

- **反转传统设计顺序**：不先指定参考 SDE，再分析其诱导分布；而是先规定一族易于处理的条件分布 \(\{\rho_t\}_{t \in [0,1]}\)，然后构造一个参考 SDE，使其边缘分布恰为给定的 \(\rho_t\)。
- 要求条件分布满足：
  1. \(\rho_t(z|x)\) 关于 \((t,z)\) 是 \(C^{1,2}\) 的；
  2. 可从 \(\rho_t(\cdot|x)\) 直接采样；
  3. 边缘分布满足边界条件：
     \[
     p_0(z) = \pi(z),\quad p_1(z) = \mu(z),
     \]
     其中
     \[
     p_t(z) := \int dx\, \rho_t(z|x)\mu(x).
     \]

### 2.2 参考过程的构造

- 寻找系数 \(\alpha(t,z,x)\) 与 \(b(t,z)\)，使条件分布 \(\rho_t\) 满足正向 Fokker-Planck 方程：
  \[
  \partial_t \rho_t(z|x) = -\nabla_z \cdot [\alpha(t,z,x)\rho_t(z|x)] + \frac{1}{2}\sum_{i,j} \partial_{z_i}\partial_{z_j} [\Gamma_{ij}(t,z)\rho_t(z|x)],
  \]
  其中 \(\Gamma = bb^\top\)。
- 定义聚合漂移：
  \[
  a(t,z) := \int dx\, \alpha(t,z,x) \frac{\rho_t(z|x)\mu(x)}{p_t(z)}.
  \]
- 于是参考过程由 SDE
  \[
  dZ_t = a(t,Z_t)dt + b(t,Z_t)\cdot dW_t,\quad Z_0 \sim p_0
  \]
  给出，其边缘分布恰为 \(p_t\)，从而在有限区间 \([0,1]\) 内连接 \(\pi\) 与 \(\mu\)。

### 2.3 无模拟目标函数

- 利用 Girsanov 定理，路径空间 KL 散度可写为：
  \[
  \mathcal{L}_{\text{DM}}(\theta) = \mathbb{E}_{Z_{[0,1]} \sim \mathcal{P}} \left[ \frac{1}{2}\int_0^1 dt\, \lVert a(t,Z_t) - s_\theta(t,Z_t) \rVert_{\Gamma(t,Z_t)^{-1}}^2 \right].
  \]
- 由于边界条件使初始分布项消失，进一步利用 \(\rho_t\) 与 \(a,\alpha\) 的关系，可将其化为无模拟目标（至多相差与 \(\theta\) 无关的常数）：
  \[
  \mathcal{L}_{\text{SF}}(\theta) = \frac{1}{2n}\sum_{i=1}^n \int_0^1 dt\, \mathbb{E}_{Z \sim \rho_t(\cdot|x_i)} \left[ \lVert \alpha(t,Z,x_i) - s_\theta(t,Z) \rVert_{\Gamma(t,Z)^{-1}}^2 \right].
  \]
- 该目标仅需直接采样 \(\rho_t\) 和计算条件漂移 \(\alpha\)，无需模拟参考 SDE，从而实现了无模拟训练。

### 2.4 具体构造实例

- **高斯先验**：令
  \[
  \rho_t(z|x) = \mathcal{N}(z; m_t(x), \sigma(t)^2 I_d),
  \]
  且 \(m_0(x)=0, m_1(x)=x, \sigma(0)=1, \sigma(1)=0\)。可解得：
  \[
  \alpha(t,z,x) = \partial_t m_t(x) + \left( \frac{\dot{\sigma}(t)}{\sigma(t)} - \frac{1}{2}\lambda(t) \right)(z - m_t(x)),
  \]
  \[
  b(t) = \sqrt{\lambda(t)}\,\sigma(t) I_d.
  \]
  采样使用重参数化技巧 \(Z = m_t(x) + \sigma(t)\xi\)。

- **非高斯先验**：采用推前（push-forward）构造。令 \(\zeta_t\) 为以 \(\pi\) 为平稳分布的扩散过程的边缘分布（因初值取 \(\pi\)，故恒有 \(\zeta_t = \pi\)）。定义双射 \(\phi_t^x\)，令
  \[
  \rho_t(z|x) = (\phi_t^x)_* \zeta_t(z),
  \]
  并利用 Itô 公式导出条件 SDE 的漂移与扩散系数：
  \[
  \alpha(t,z,x) = \partial_t \phi_t^x(y(z)) + \frac{1}{2}\gamma(t)\left[ D_y \phi_t^x(y(z)) \nabla_y \log \pi(y(z)) + \nabla_y^2 \phi_t^x(y(z)) \right],
  \]
  \[
  \beta(t,z,x) = \sqrt{\gamma(t)}\, D_y \phi_t^x(y(z)).
  \]
  为使扩散系数与 \(x\) 无关，要求 \(\phi_t^x(y) = f_t(y + g_t(x))\)，其中 \(f_t\) 为光滑双射。

### 2.5 与已有方法的理论联系

- **得分匹配并非必需**：传统方法从数据到先验的方向构造参考过程，时间反转引入得分 \(\nabla_x \log p_t\)；本文直接从生成方向构造参考过程，避免得分出现，因此得分匹配只是参考过程反转的自然结果。
- **条件流匹配（CFM）是小噪声极限**：将式中的 \(\gamma(t)\) 替换为 \(\epsilon\gamma(t)\)，令 \(\epsilon \to 0\)，目标函数收敛到 CFM 目标：
  \[
  \lim_{\epsilon \to 0} \epsilon \mathcal{L}_{\text{SF}}(\theta;\epsilon) = \frac{1}{2n}\sum_{i=1}^n \int_0^1 dt\, \mathbb{E}_{Z \sim \rho_t(\cdot|x_i)} \left[ \lVert \bar{\alpha}(t,Z,x_i) - s_\theta(t,Z) \rVert_{I_d}^2 \right],
  \]
  其中 \(\bar{\alpha}\) 满足连续性方程。这给出了 CFM 的“随机提升”（stochastic lift）解释。
- **流动扩散模型（如 NFDM）** 从确定性路径出发加噪，会重新出现条件得分，而本文构造不依赖得分。
- **随机定位（SL）** 可视为在目标分布为显式密度 \(p_{\text{true}}\) 时，本文框架在有限时间连接先验与目标的特例。

## 7. 方法的主要优点与局限性

### 7.1 主要优点

- **理论框架的统一性**：将基于得分的扩散模型、条件流匹配、随机定位等方法纳入统一的路径空间视角，阐明了它们之间的内在联系与差异。
- **消除时间尺度调节**：有限时间生成避免了 OU 过程渐近收敛导致的长时间模拟问题，在实际应用中无需针对不同数据集调节 \(T\)，简化了使用流程。
- **无模拟训练的可扩展性**：目标函数仅需求条件分布 \(\rho_t\) 的样本和条件漂移 \(\alpha\)，与参考 SDE 的模拟解耦，计算开销较低，且易于与现有深度学习框架结合。
- **对先验分布的灵活性**：不仅支持高斯先验，还可通过 push-forward 构造支持非高斯先验，拓宽了扩散模型的应用范围。
- **理论解释深刻**：对“得分匹配是否必要”这一问题的回答，为未来设计新的扩散模型提供了理论指导。

### 7.2 主要局限性

- **条件分布的构造依赖人工设计**：虽然论文给出了高斯与 push-forward 两类构造方法，但如何针对特定任务自动选择最优的 \(\rho_t\) 仍是一个开放问题，缺乏一般性的指导准则。
- **扩散系数均匀性限制**：为使无模拟目标形式简洁，要求扩散系数 \(\Gamma(t,z)\) 与 \(x\) 无关，这限制了可构造的参考过程族，尤其是在 push-forward 构造中要求强约束的 \(\phi_t^x(y) = f_t(y+g_t(x))\) 形式。
- **缺少高维与大规模验证**：实验仅限二维 toy dataset，无法证实方法在高维图像、文本或音频等实际场景中的有效性，也未能展示与现有主流方法（如 DDPM、Score SDE、Rectified Flow）在同等规模下的性能对比。
- **理论分析深度有限**：对近似误差（如有限步离散化、\(\rho_t\) 满足 Fokker-Planck 方程的近似程度）缺乏误差传播分析，也没有讨论 \(s_\theta\) 的模型容量对生成质量的影响。
