## 摘要
我们对薛定谔桥时间序列（SBTS）数据生成器进行了收敛性分析。从正则化公式出发，其中数据集成以指定概率与标准多元高斯分布混合，我们证明了Euler-Maruyama离散化以半阶收敛速率收敛到混合目标分布，前提是集成大小和核带宽选择得当。我们进一步表明，随着混合概率趋于零，正则化分布收敛到原始目标分布。该分析同时考虑了集成近似误差、核近似误差和时间离散误差，因此为SBTS生成器提供了完整的分布收敛结果。在实证中，我们进一步考察了该方法的灵活性，通过将维纳参考测度替换为由更一般的SDE诱导的路径测度。数值实验表明，基于原始维纳参考测度和SDE诱导参考测度的方案均取得了可比的性能，展示了SBTS框架的鲁棒性和稳定性。

## Abstract
We conduct a convergence analysis for the Schrödinger Bridge Time Series (SBTS) data generator. Starting from a regularized formulation in which the data ensemble is mixed with a standard multivariate Gaussian distribution with a prescribed probability, we prove that the Euler-Maruyama discretization converges to the mixed target distribution with half-order convergence rate, provided that the ensemble size and kernel bandwidth are chosen appropriately. We further show that the regularized distribution converges to the original target distribution as the mixing probability tends to zero. The analysis simultaneously accounts for the ensemble approximation error, kernel approximation error, and time-discretization error, and therefore provides a full distributional convergence result for the SBTS generator. Empirically, we further examine the flexibility of the method by replacing the Wiener reference measure with the path measure induced by a more general SDE. The numerical experiments show that the schemes based on both the original Wiener reference measure and the SDE-induced reference measure achieve comparable performance, demonstrating the robustness and stability of the SBTS framework.

### 2. 方法论

#### 2.1 正则化构造

- 由于原始密度比 \(\mu_n / \mu_n^G\) 可能趋于零，导致漂移中的 Lipschitz 常数无法控制，论文引入**高斯混合正则化**：

\[
\mu^\epsilon := (1-\epsilon)\mu + \epsilon \mu^G,\quad \epsilon\in(0,1)
\]

其中 \(\mu^G\) 为布朗运动在观测网格上的联合分布。该混合保证了下述条件期望分母一致有正下界 \(\ge \epsilon\)，从而可以证明漂移的平滑性。

#### 2.2 SBTS 的漂移表示

- 原始 SBTS 由分段 SDE 驱动：

\[
dX_t = \alpha(t, X_t; X_{t_1:\eta(t)})dt + dW_t,\quad X_0=0
\]

其中漂移含条件期望。正则化后，漂移可写成高斯期望下的对数梯度形式：

\[
\alpha^\epsilon(t,x;x_{1:n})
= \nabla_x \log \mathbb{E}_{Y\sim \mathcal{N}(0,I_d)}
\left[
\frac{\mu_{n+1}^\epsilon(x_1,\ldots,x_n,x+\sqrt{t_{n+1}-t}\,Y)}
{\mu_{n+1}^G(x_1,\ldots,x_n,x+\sqrt{t_{n+1}-t}\,Y)}
\right]
\]

- 通过代数变换，正则化漂移进一步写成**分子与分母分别积分**的比值形式，便于用核密度估计近似。

#### 2.3 核估计与 Euler-Maruyama 离散化

- 使用两组独立样本 \(\{X^i_{t_1:t_N}\}_{i=1}^M\) 和 \(\{\tilde X^i_{t_1:t_N}\}_{i=1}^M\) 构造核估计：

\[
d_{\epsilon,M} = \frac{1}{M}\sum_{i=1}^M \nabla_x F_n(t,X^i_{t_n},x,X^i_{t_{n+1}})\exp_n(X^i_{t_1:t_n}) \prod_{j=1}^n K_H(x_j-X^i_{t_j})
\]

\[
e_{\epsilon,M} = \frac{1}{M}\sum_{i=1}^M F_n(t,\tilde X^i_{t_n},x,\tilde X^i_{t_{n+1}})\exp_n(\tilde X^i_{t_1:t_n}) \prod_{j=1}^n K_H(x_j-\tilde X^i_{t_j})
\]

- 近似漂移为：

\[
\alpha^{\epsilon,M}(t,x;x_{1:n}) = \frac{(1-\epsilon)C_t d_{\epsilon,M}}{(1-\epsilon)C_t e_{\epsilon,M} + \epsilon C_G^{n+1}}
\]

- 时间离散化采用经典 Euler-Maruyama 格式，步长 \(h=1/m\)，逐区间更新样本路径。

#### 2.4 收敛性分析结构

- 论文将误差分解为三部分：
  1. **正则化误差**：\(W_2^2(\mu^\epsilon,\mu) \le \epsilon \mathbb{E}|Y-Z|^2 \sim O(\epsilon)\)。
  2. **漂移拟合误差**：核估计偏差阶为 \(O(H^4)\)，蒙特卡洛统计误差阶为 \(O(1/(M H^{2nd}))\)。
  3. **时间离散误差**：利用漂移的 Lipschitz 和线性增长性质，证明强误差累积满足递推不等式。

- 最终定理给出：

\[
W_2^2(\mu^{\epsilon,N,M},\mu) \sim \mathcal{O}(h) + \mathcal{O}(\epsilon)
\]

要求每个区间上带宽 \(H \sim \mathcal{O}(h^{1/2})\)，样本量 \(M \sim \mathcal{O}(h^{-((n+1)d+2)})\)。

### 6. 主要结论与发现

- 在适当选取带宽 \(H\sim O(h^{1/2})\) 和样本量 \(M\sim O(h^{-((n+1)d+2)})\) 条件下，SBTS 的 Euler-Maruyama 近似以 \(\mathcal{O}(h^{1/2})\) 强收敛率收敛到正则化混合分布，并进一步得到分布级 Wasserstein 误差界：

\[
W_2^2(\mu^{\epsilon,N,M},\mu) \sim \mathcal{O}(h) + \mathcal{O}(\epsilon)
\]

- 正则化参数 \(\epsilon\) 越小，生成分布越接近原始目标分布，数值实验证实了该趋势。
