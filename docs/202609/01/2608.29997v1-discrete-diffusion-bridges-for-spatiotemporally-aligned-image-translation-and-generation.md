## 摘要
我们提出了离散扩散桥（DDB），一种新颖的框架，旨在解决标准离散扩散在图像翻译和生成中根本的时空错位问题。通过随机调度将数据破坏为纯掩码状态，传统的前向过程引入了双重错位：在空间上，这种纯掩码目标完全丢弃了源图像丰富的结构先验；在时间上，随机掩码顺序本质上与推理期间使用的“易先难后”的解码机制相矛盾。为了解决这一问题，DDB在域之间构建了一条直接且高效的轨迹。在空间上，我们引入了一种混合吸收机制，将吸收状态重新定义为掩码和源标记的随机混合，有效地将源先验作为空间锚点注入潜在空间。在时间上，我们设计了一种信息引导的噪声调度，通过量化语义变化来优先在更早的时间步破坏高信息区域。这确保了模型能够利用不变区域的稳健上下文来解决困难的语义变化。大量实验验证了我们框架在不同生成范式中的多样性和稳健性。DDB在文本引导的语义操作和纯结构图像翻译中有效平衡了编辑对齐与结构保真度，同时内在补充了文本到图像的生成，并保证在极低采样步数下稳健的高质量解码。代码和模型可在\href{https://github.com/HKU-HealthAI/DDB}{https://github.com/HKU-HealthAI/DDB}获取。

## Abstract
We propose Discrete Diffusion Bridges (DDB), a novel framework designed to resolve the fundamental spatiotemporal misalignment of standard discrete diffusion in image translation and generation. By corrupting data into a pure mask state via a random schedule, the conventional forward process induces a twofold misalignment: spatially, this pure-mask destination entirely discards the rich structural priors of the source image; temporally, the random masking order inherently contradicts the ``easy-first, hard-last'' decoding mechanism used during inference. To address this, DDB constructs a direct and efficient trajectory between domains. Spatially, we introduce a hybrid absorption mechanism that redefines the absorbing state to a stochastic mixture of mask and source tokens, effectively injecting source prior as spatial anchors into the latent space. Temporally, we design an information-guided noise schedule that quantifies semantic variation to prioritize the corruption of high-information regions at earlier timesteps. This ensures the model learns to resolve difficult semantic changes using robust context from invariant regions. Extensive experiments validate the versatility and robustness of our framework across diverse generative paradigms. DDB effectively balances edit alignment with structural fidelity across both text-guided semantic manipulation and pure structural image translation, while inherently complementing text-to-image generation and guaranteeing robust high-quality decoding under extremely low sampling steps. Code and models are available at \href{https://github.com/HKU-HealthAI/DDB}{https://github.com/HKU-HealthAI/DDB}.

### 1. 论文的核心问题与整体含义

标准离散扩散模型在图像翻译与生成任务中存在**根本性的时空错位问题**：

- **空间错位**：传统前向过程通过随机调度将数据破坏为**纯掩码（pure mask）吸收态**，该目标状态完全丢弃了源图像蕴含的结构先验信息，导致源域与目标域之间缺乏直接的空间对应关系。
- **时间错位**：前向过程中**随机的掩码顺序**与推理阶段普遍采用的“先易后难（easy-first, hard-last）”解码机制存在本质矛盾——模型在解码初期就被要求解决最困难的语义变化，却缺乏不变区域的上下文支撑。

这一问题的核心含义在于：**离散扩散模型在跨域生成任务中需要一个同时满足空间对齐与时间对齐的直接高效轨迹**，而现有的模型并未针对这两个维度进行专门设计。论文通过构建**离散扩散桥（DDB）**，将源域先验显式地注入扩散过程，从根本上缓解上述双重错位。

### 2. 论文提出的方法论

#### 2.1 核心思想：在域间构建直接轨迹

DDB 不在标准掩码扩散的单域轨迹上运行，而是在**源域与目标域之间直接构造一条扩散桥**。该桥在空间与时间两个维度上分别对齐源与目标的语义结构。

#### 2.2 空间维度：混合吸收机制（Hybrid Absorption）

- 传统吸收扩散将吸收态定义为**纯掩码 token**，即 \( x_{\text{absorb}} = [\text{MASK}] \)。
- DDB 将吸收态重新定义为**掩码 token 与源 token 的随机混合**：
  \[
  x_t \sim q_{\text{hybrid}}(x_t \mid x_0, x_{\text{source}})
  \]
  其中每个位置的 token 以一定概率被替换为掩码，或以另一概率替换为**源图像对应位置的 token**。
- 这一设计将源图像的 token 作为**空间锚点**注入潜在空间，使模型在任意时间步都能访问源图像的结构信息。即使在扩散后期，模型仍能通过不变区域的源 token 获得上下文指导。

#### 2.3 时间维度：信息引导的噪声调度（Information-Guided Noise Schedule）

- DDB 量化每个空间位置的**语义变化程度**，据此定义一个信息量度量 \( \mathcal{I}(x_{\text{source}}, x_{\text{target}}) \)。
- 噪声调度不再均匀或随机地掩码，而是**优先在更早的时间步破坏高信息量区域**：
  \[
  \text{掩码概率} \propto \mathcal{I}(x_{\text{source}}, x_{\text{target}})
  \]
- 这使得模型在推理初期就被迫关注具有较大语义差异的区域，同时利用不变区域（低信息量区域）的源 token 作为上下文，从而**更稳健地解决困难的语义变化**。

#### 2.4 整体流程表述

1. **前向过程**：从目标图像开始，按照信息引导的调度逐步用掩码或源 token 替换目标 token，形成一个介于源与目标之间的中间状态序列。
2. **反向过程**：训练一个离散扩散模型，学习在给定中间状态（由源 token 与掩码混合构成）和源图像的条件下，逐步还原目标 token。
3. **推理阶段**：在极低采样步数下，模型从全掩码（或部分源 token）状态开始，按“先易后难”的顺序解码，利用源 token 的空间锚定作用逐级还原目标图像。
