## 摘要
我们提出并分析了在给定截止时间（有限时域）内连续时间下的线性指数二次高斯（LEQG）协方差引导问题。该问题的解可视为线性二次设定下高斯端点之间的风险敏感薛定谔桥。与风险中性情形不同，LEQG 协方差引导控制器——仍为线性状态反馈——不再能写成闭式形式。我们证明，最优控制器可由一个对称矩阵参数化，该矩阵满足一个代数方程，该方程刻画了对风险敏感参数的隐式依赖。我们解释了该最优控制器的结构如何显著推广了风险中性情形的现有结果。基于这些结果，对于噪声与输入通道匹配的情形，我们证明了 LEQG 协方差引导问题在已知风险中性最优解邻域内解的存在唯一性。我们给出一个说明性的数值例子。

## Abstract
We formulate and analyze the linear exponential quadratic Gaussian (LEQG) covariance steering problem in continuous time over a given deadline (finite time horizon). The solution for this problem can be seen as a risk-sensitive Schrödinger bridge between Gaussian endpoints in the linear quadratic setting. Unlike the risk-neutral case, the LEQG covariance steering controller--still a linear state feedback--can no longer be written in closed form. We show that the optimal controller is parameterized by a symmetric matrix solving an algebraic equation that encodes the implicit dependence on the risk-sensitivity parameter. We explain how the structure of this optimal controller significantly generalizes the existing results for the risk-neutral case. Building on these results, for the matched noise and input channel case, we prove the existence-uniqueness of solution for the LEQG covariance steering problem in the neighborhood of the known risk-neutral optimal solution. We give an illustrative numerical example.

## 1. 核心问题与整体含义

- **研究背景**：风险中性（risk-neutral）的线性二次高斯（LQG）协方差引导（covariance steering）问题已有较完整的理论，如 Chen–Georgiou–Pavon 系列工作（[1][6][7]）分别处理了 \(F_t=B_t, Q_t\equiv 0\)、\(F_t\neq B_t\)、以及 \(F_t=B_t, Q_t\succeq 0\) 等情形，且最优控制器可写成闭式。
- **核心问题**：本文首次提出并分析**连续时间、有限时域**下的**线性指数二次高斯（LEQG）协方差引导问题**：
  \[
  \inf_{\gamma\in\Gamma}\ \frac{1}{\theta}\log \mathbb{E}\left[\exp(\theta C)\right],\qquad C:=\int_0^1 \frac{1}{2}\left(x_t^\top Q_t x_t + u_t^\top R_t u_t\right)dt
  \]
  约束于线性随机动力学 \(dx_t = (A_t x_t + B_t u_t)dt + F_t dw_t\)，且端点状态服从给定协方差的高斯分布 \(x_0\sim\mathcal{N}(0,\Sigma_0)\)、\(x_1\sim\mathcal{N}(0,\Sigma_1)\)。
- **整体含义**：该问题可视为**线性二次框架下高斯端点之间的风险敏感薛定谔桥**。风险敏感参数 \(\theta\) 刻画了决策者态度：
  - \(\theta\to 0\) 由洛必达法则退化为风险中性 \(\mathbb{E}[C]\)；
  - \(\theta>0\) 为**风险厌恶**（risk-averse），对高代价实现惩罚更重；
  - \(\theta<0\) 为**风险寻求**（risk-seeking）。
- **动机**：当随机代价 \(C\) 方差较大时，风险中性控制器可能过于乐观；LEQG 目标函数 \(\frac{1}{\theta}\log\mathbb{E}[e^{\theta C}]\) 是 \(C\) 的对数矩生成函数，可导出更保守、在最坏情况下表现更好的控制器。
- **与已有 LEQG 控制的区别**：经典 LEQG 问题（Jacobson、Whittle、Lim–Zhou、Duncan 等）含终端代价，而本文问题**无终端代价**，取而代之的是**端点协方差约束**，因此解的结构与经典结果不同。

## 2. 方法论

### 2.1 核心思想

- 通过线性二次随机控制理论（Pontryagin 极小值原理），证明**最优控制器仍是线性状态反馈**：
  \[
  \gamma_{\text{opt}}(t,x) = -R_t^{-1}B_t^\top \Pi_{t|\theta}\, x
  \]
  其中 \(\Pi_{t|\theta}\) 为与 \(\theta\) 相关的时变对称矩阵（下标 \(t|\theta\) 表示对 \(\theta\) 的参数依赖）。
- 与风险中性情形不同，\(\Pi_{t|\theta}\) **无法写成闭式**，而是由**隐式代数方程**确定。

### 2.2 必要最优性条件

- 最优性必要条件给出协方差–协态对 \((\Sigma_{t|\theta},\Pi_{t|\theta})\) 的**单向耦合 Lyapunov–Riccati 微分方程边值问题（BVP）**，仅协方差端点条件：
  \[
  \dot\Sigma_{t|\theta} = \left(A_t - B_t R_t^{-1}B_t^\top \Pi_{t|\theta}\right)\Sigma_{t|\theta} + \Sigma_{t|\theta}\left(A_t - B_t R_t^{-1}B_t^\top \Pi_{t|\theta}\right)^\top + F_t F_t^\top
  \]
  \[
  -\dot\Pi_{t|\theta} = A_t^\top \Pi_{t|\theta} + \Pi_{t|\theta}A_t + Q_t - \Pi_{t|\theta}\left(B_t R_t^{-1}B_t^\top - \theta F_t F_t^\top\right)\Pi_{t|\theta}
  \]
  边界条件 \(\Sigma_0 = \Sigma_{0}\)，\(\Sigma_1=\Sigma_1\)。
- 引入 Chen–Georgiou–Pavon 的**变量替换**：
  \[
  H_{t|\theta} := \Sigma_{t|\theta}^{-1} - \Pi_{t|\theta}
  \]
  将 Lyapunov–Riccati BVP 改写为关于不定对 \((H_{t|\theta},\Pi_{t|\theta})\) 的**Riccati–Riccati BVP**：
  \[
  -\dot H_{t|\theta} = A_t^\top H_{t|\theta} + H_{t|\theta}A_t + H_{t|\theta}B_tR_t^{-1}B_t^\top H_{t|\theta} - Q_t
  \]
  \[
  -\left(\Pi_{t|\theta}+H_{t|\theta}\right)\left(B_tR_t^{-1}B_t^\top - F_tF_t^\top\right)\left(\Pi_{t|\theta}+H_{t|\theta}\right) - \theta\,\Pi_{t|\theta}F_tF_t^\top\Pi_{t|\theta}
  \]
  \[
  -\dot\Pi_{t|\theta} = A_t^\top\Pi_{t|\theta} + \Pi_{t|\theta}A_t + Q_t - \Pi_{t|\theta}\left(B_tR_t^{-1}B_t^\top - \theta F_tF_t^\top\right)\Pi_{t|\theta}
  \]
  以及边界条件 \(\Sigma_0^{-1}=\Pi_{0|\theta}+H_{0|\theta}\)，\(\Sigma_1^{-1}=\Pi_{1|\theta}+H_{1|\theta}\)。
- 当 \(\theta=0\) 时，高亮项消失；若进一步满足**匹配通道条件** \(F_tF_t^\top = B_tR_t^{-1}B_t^\top\)，则退化为文献 [7] 的 BVP。

### 2.3 匹配通道情形的化简

在匹配通道条件下，系统简化为：
\[
-\dot H_{t|\theta} = A_t^\top H_{t|\theta} + H_{t|\theta}A_t + H_{t|\theta}B_tR_t^{-1}B_t^\top H_{t|\theta} - Q_t - \theta\,\Pi_{t|\theta}B_tR_t^{-1}B_t^\top\Pi_{t|\theta}
\]
\[
-\dot\Pi_{t|\theta} = A_t^\top\Pi_{t|\theta} + \Pi_{t|\theta}A_t + Q_t + (\theta-1)\Pi_{t|\theta}B_tR_t^{-1}B_t^\top\Pi_{t|\theta}
\]
其中含 \(\theta\) 的项即与风险中性情形的差别所在。

### 2.4 参数化结构：隐式代数方程

- 将 Riccati ODE 的解用**线性 Hamilton 系统**的基本解矩阵（STM）表示：
  - \(\hat M_{t|\theta}\) 对应 \(H\) 的 Hamilton 系统，其系数**显式依赖** \(\Pi_{t|\theta}\)（进而依赖 \(Y_{0|\theta}\)）；
  - \(M_{t|\theta}\) 对应 \(\Pi\) 的 Hamilton 系统，其系数不依赖 \(Y_{0|\theta}\)。
- 由线性分式表示（linear fractional representation）：
  \[
  H_{t|\theta} = -\left(\hat X_{t|\theta}^\top\right)^{-1}\hat Y_{t|\theta}^\top,\qquad \Pi_{t|\theta}=Y_{t|\theta}X_{t|\theta}^{-1}
  \]
  其中 \(X_{t|\theta}=\Phi^{11}_{0\to t|\theta}+\Phi^{12}_{0\to t|\theta}Y_{0|\theta}\)，\(Y_{t|\theta}=\Phi^{21}_{0\to t|\theta}+\Phi^{22}_{0\to t|\theta}Y_{0|\theta}\)。
- 关键观察（**Remark 1**）：\(\theta\neq 0\) 时 \(\hat M_{t|\theta}\neq M_{t|\theta}\)，故 \(\hat\Phi_{s\to t|\theta}\neq \Phi_{s\to t|\theta}\)，**辛几何恒等式不再同时成立**，因此无法像风险中性情形那样把端点条件化为二次方程并用配方法求解。
- 最终得到一个关于未知对称矩阵 \(Y_{0|\theta}\) 的**隐式代数方程**：
  \[
  G(\theta, Y_{0|\theta}) := \Pi_{1|\theta} + H_{1|\theta} - \Sigma_1^{-1} = 0
  \]
  一旦解出 \(Y_{0|\theta}\)，即可确定 \(\Pi_{t|\theta}\) 与最优控制。

### 2.5 存在唯一性证明路线（Theorem 1）

证明依赖以下辅助结果，构成一条完整的逻辑链：

1. **Proposition 2（正则性）**：借助参数依赖 ODE 的光滑性定理，证明映射 \((\theta,Y_{0|\theta})\mapsto \Pi_{t|\theta}\mapsto H_{t|\theta}\mapsto G(\theta,Y_{0|\theta})\) 在紧致开集上是 \(C^1\) 的。
2. **Lemma 1（Jacobian 显式）**：在 \(\theta=0\) 处
   \[
   D_{Y_{0|0}}G = X_{1|0}^{-\top}\otimes X_{1|0}^{-\top} - \hat X_{1|0}^{-\top}\otimes \hat X_{1|0}^{-\top}
   \]
   推导中用到辛恒等式与 Kronecker 积的向量化技巧。
3. **Remark 2**：给出 \(\theta\neq 0\) 时 Jacobian 的一般表达式，含积分项 \(\theta\int_0^1\left(U_{s|\theta}\otimes V_{s|\theta}+V_{s|\theta}\otimes U_{s|\theta}\right)ds\)（用于未来推广，本文证明未用）。
4. **Proposition 3（Jacobian 非奇异）**：利用风险中性解 \(Y_{0|0}^-\) 的显式表达式，构造
   \[
   \Psi_{01} := \Sigma_0^{-1/2}\left(\tfrac14 I + \Sigma_0^{1/2}(\Phi^{12}_{0\to1})^{-1}\Sigma_1(\Phi^{12}_{0\to1})^{-\top}\Sigma_0^{1/2}\right)^{1/2}\Sigma_0^{-1/2},\quad S_0 := \tfrac12\Sigma_0^{-1}
   \]
   证明 \(\Psi_{01}\succ 0\)、\(\Psi_{01}-S_0\succ 0\)，并通过同时对角化证明
   \[
   \Omega := \left(\Psi_{01}-S_0\right)^{-1}\otimes\left(\Psi_{01}-S_0\right)^{-1} - \left(\Psi_{01}+S_0\right)^{-1}\otimes\left(\Psi_{01}+S_0\right)^{-1} \succ 0
   \]
   其谱为 \(\frac{2(\psi_i+\psi_j)}{(\psi_i^2-1)(\psi_j^2-1)}>0\)，从而 \(D_{Y_{0|0}}G\big|_{Y^-_{0|0}}\) 非奇异。
5. **Theorem 1（主结果）**：由**隐函数定理**，存在开区间 \(I\ni 0\) 与开邻域 \(U\ni Y^-_{0|0}\)，以及唯一的 \(C^1\) 映射 \(h:I\to U\)，满足 \(h(0)=Y^-_{0|0}\) 且 \(G(\theta,h(\theta))=0\ \forall\theta\in I\)。即 LEQG 问题在风险中性最优解处存在**局部 \(C^1\) 解分支**。
