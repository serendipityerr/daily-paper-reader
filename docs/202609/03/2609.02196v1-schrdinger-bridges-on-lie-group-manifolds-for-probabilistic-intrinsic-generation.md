## 摘要
直接在几何流形上进行生成建模可以避免将非欧几里得数据展平、重复的环境投影以及欧几里得表示中的坐标不一致所带来的误差。薛定谔桥为规定的端点分布之间的熵正则化输运提供了一种概率生成框架。我们研究了李群流形上状态X_t = (g_t, xi_t)位于G×g中的动力学薛定谔桥，允许端点观测仅约束实际测量的变量。特别地，熵投影决定了未观测端点速度的条件分布。对于相同的观测端点桥，我们开发了两种计算实现：包裹核桥校准（WKBC）在紧致阿贝尔群上使用显式的周期化动力学核，而互易条件控制桥匹配（RCCBM）通过双侧端点校准和磨光条件控制匹配来处理紧致非阿贝尔群。规范教师混合路径律本身就是一个马尔可夫互易律，因此前向生成使用校准的初始律和一个学习到的Doob控制器。此外，我们在有界-利普希茨路径度量中建立了一个模块化误差界，该误差界清晰地分离了端点、控制回归、初始化、离散化及相关近似引起的误差。在多个李群流形数据集上的实验验证了我们提出方法的可行性和一致性，涵盖了蛋白质和RNA扭转角、SO(3)、U(n)，以及使用紧凑降维表示中mdCATH轨迹的蛋白质构象转变路径生成任务。源代码可在https://github.com/cafferyzhang12/Schr-dinger_Bridge_on_LieGroup公开获取。

## Abstract
Generative modeling directly on geometric manifolds can avoid errors introduced by flattening non-Euclidean data, repeated ambient projection, and coordinate inconsistency in Euclidean representations. Schrodinger bridges provide a probabilistic generative framework for entropy-regularized transport between prescribed endpoint distributions. We study Schrodinger bridges for kinetic dynamics on Lie group manifolds with state X_t = (g_t, xi_t) in G x g, allowing endpoint observations to constrain only the variables that are actually measured. In particular, the entropy projection determines the conditional law of the unobserved endpoint velocities.   For the same observed endpoint bridge, we develop two computational realizations: Wrapped-Kernel Bridge Calibration (WKBC) uses an explicit periodized kinetic kernel on compact Abelian groups, whereas Reciprocal Conditional-Control Bridge Matching (RCCBM) handles compact non-Abelian groups through two-sided endpoint calibration and mollified conditional-control matching. The canonical teacher-mixture path law is itself a Markov reciprocal law, so forward generation uses a calibrated initial law and one learned Doob controller. Moreover, we establish a modular error bound in the bounded-Lipschitz path metric that provides a clean separation of errors due to endpoints, control regression, initialization, discretization, and related approximations.   Experiments on multiple Lie group manifold datasets validate the feasibility and consistency of our proposed method, covering protein and RNA torsions, SO(3), U(n), and the Protein Conformational Transition Pathway Generation task using mdCATH trajectories in a compact reduced representation. The source code is publicly available at https://github.com/cafferyzhang12/Schr-dinger_Bridge_on_LieGroup.

## 2. 论文提出的方法论

### 2.1 核心思想

- 在状态空间 \(X_t = (g_t, \xi_t) \in G \times \mathfrak{g}\) 上定义动力学薛定谔桥（Schrödinger bridge）：
  - \(g_t\)：群位置（Lie群 \(G\) 中的元素）；
  - \(\xi_t\)：速度或“动量”变量（位于对应Lie代数 \(\mathfrak{g}\)）。
- 薛定谔桥的目标是在规定的端点分布之间执行熵正则化输运；与经典设置不同，本文允许端点观测**仅约束实际测量到的变量**。
- 关键特别之处在于：当观测仅约束位置 \(g\) 而不直接测到端点速度 \(\xi\) 时，**熵投影**会决定未观测端点速度的条件分布，从而让桥过程保持动力学一致性。

### 2.2 关键技术细节

- **熵投影机制**：对于仅给出部分端点信息的观测桥，系统通过把端点分布投射到满足熵正则化约束的条件律上，推出未观测端点速度的后验分布，从而唯一确定整体动力学。
- **马尔可夫互逆律**：
  - 从**规范教师混合路径律**（canonical teacher-mixture path law）出发生成的路径律本身就是**马尔可夫互逆律**。
  - 因此可把整个前向生成过程分解为两个可控组件：
    - 一个**校准后的初始律**；
    - 一个**学习到的 Doob 控制器**（Doob \(h\)-transform 意义上的控制器），用于在有限时间区间内将初始分布搬移到目标端点分布。
- **两种计算实现**（针对同一种观测端点桥）：
  1. **WKBC（Wrapped-Kernel Bridge Calibration，包裹核桥校准）**
     - 针对 **紧致阿贝尔群**；
     - 使用显式的周期化核（periodized kinetic kernel）构造桥过程。这样做的好处是可以在频域上精确或半解析地计算核，从而高效完成校准。
  2. **RCCBM（Reciprocal Conditional-Control Bridge Matching，互易条件控制桥匹配）**
     - 针对 **紧致非阿贝尔群**；
     - 通过**双侧端点校准**（从两个方向、分别匹配终点/起点条件分布）和**磨光条件控制匹配**（对条件控制器做光滑化近似）来学习前向桥；
     - 主要解决非交换情形下显式核难以求解的问题。

### 2.3 公式与算法流程概述

- 动力学定义在李群 \(\times\) 李代数上，即
  \[
  X_t = (g_t, \xi_t) \in G \times \mathfrak{g},
  \]
  其中平移与速度耦合项决定了如何把Lie代数中的速度映射回群流形。
- 熵正则化问题一般可写成最小化相对熵的形式：对于参考测度 \( \mathbb{Q} \) 与端点边际 \(\mu_0, \mu_T\)，求
  \[
  \mathbb{P}^* = \arg\min_{\mathbb{P} : \operatorname{Law}(g_0)=\mu_0,\ \operatorname{Law}(g_T)=\mu_T} D_{\mathrm{KL}}(\mathbb{P} \parallel \mathbb{Q}),
  \]
  当只约束位置 \(g\) 而不约束速度 \(\xi\) 时，端点条件由熵投影得到。
- WKBC 的做法：
  1. 选取紧致阿贝尔群上的周期化动力学核；
  2. 在频域上完成端点校准，得到桥核；
  3. 从前向初始律 + Doob 控制器采样路径。
- RCCBM 的做法：
  1. 自左右两端分别做条件控制匹配（对非阿贝尔群使用共轭作用处理坐标不对齐问题）；
  2. 用磨光算子平滑条件控制器；
  3. 使用校准后的初始律做前向采样。
- **误差界**：文中在**有界-李普希茨路径度量**下建立了如下形式的模块化误差界：
  \[
  \begin{aligned}
  d_{\mathrm{BL}}(\hat{\mathbb{P}}_n^{\text{generated}}, \mathbb{P}^{\text{true}})
  &\lesssim \underbrace{\varepsilon_{\text{endpoint}}}_{\text{端点误差}}
  + \underbrace{\varepsilon_{\text{control}}}_{\text{控制回归误差}}
  + \underbrace{\varepsilon_{\text{init}}}_{\text{初始化误差}} \\
  &\quad + \underbrace{\varepsilon_{\text{disc}}}_{\text{离散化误差}}
  + \underbrace{\varepsilon_{\text{approx}}}_{\text{相关近似误差}},
  \end{aligned}
  \]
  该误差界将不同来源的误差分离，可为算法各模块分别提供质量控制标准。

- **应用面限制**：目前验证任务是扭转角、旋转群、酉群和mdCATH构象转移路径，其他常见流形（如对称正定矩阵流形、Grassmann 流形等）没有覆盖，框架可迁移性仍需对 Grassmann/SPD 等非群流形做更多改造。
