## 摘要
量子电路优化将一个电路替换为门数更少、深度更低的等价电路，从而降低执行成本和错误率。我们提出一个问题：生成模型能否直接从示例中学习这种变换，而不是从固定的重写库或僵硬的代数例程中进行选择。我们提出了 Bridge of $Ψ$'s（BOPS），一种基于薛定谔桥的生成模型，采用定制的去噪器架构，学习从源电路到等价优化电路的变换。我们在为现有优化器构造的困难数据上训练它：通过反向应用重写规则，使每个输入都有一个已知的更低成本目标。在留出的 8 量子比特 × 64 深度 Clifford+$T$ 电路上，BOPS 在几何平均上将门数减少 2.46 倍、深度减少 2.45 倍，优于所有九个基线优化器。这构成了首个桥接量子电路与前沿机器学习方法的生成模型，为量子编译栈沿多个轴进行学习型优化开辟了道路。

## Abstract
Quantum circuit optimization replaces a circuit with an equivalent one of fewer gates and lower depth, reducing execution cost and error rate. We ask whether a generative model can learn this transformation directly from examples, rather than selecting from a fixed rewrite library or rigid algebraic routines. We present Bridge of $Ψ$'s (BOPS), a generative model based on Schrödinger bridges, using a custom denoiser architecture, that learns a transformation from a source circuit into an equivalent optimized circuit. We train it on data constructed to be hard for existing optimizers, by applying rewrite rules backwards so that each input has a known lower-cost target. On held-out 8 qubits $\times$ 64 depth Clifford+$T$ circuits, BOPS reduces gate count by $2.46\times$ and depth by $2.45\times$ in geometric mean, outperforming all nine baseline optimizers. This constitutes the first generative model bridging quantum circuits and frontier machine learning methods, opening up the quantum compilation stack to learned optimization along multiple axes.

- **痛点**：
  - 规则库固定、重合成宽度受限（如 QUESO 仅到 3 比特 4 门、GUOQ 仅到 3 比特），难以泛化到组合/嵌套的跨区域重写。
  - 学习型优化器（强化学习、序列到序列 Transformer）仍只是在**预定义动作空间**上选择策略。
  - 之前的扩散模型做的是「酉矩阵条件合成」而非「源电路条件优化」，且报告的是近似保真度误差而非精确等价。
- **核心问题**：能否让生成模型**直接从示例中学习**电路优化的变换，而无需显式的推理期重写库、无需在训练中构造酉矩阵或做等价性检验？
- **整体含义**：BOPS 是首个源条件（source-conditioned）薛定谔桥用于电路优化，也是首个匹配/超越 SOTA 硬编码与搜索型优化器的生成模型，为量子编译栈引入可学习、多目标的数据驱动优化范式。

## 2. 方法论

### 2.1 核心思想：把电路优化表述为连续传输

- 标准扩散模型将高斯噪声传输到数据；**薛定谔桥**则可在任意两个数据分布之间传输，并在**配对数据**下变得可训练。
- 关键转换：把扩散过程的噪声端点替换为**源电路**，使桥从源电路 \(x_1\) 传输到优化后的等价电路 \(x_0\)。等价性被编码进数据本身，因此无需在训练循环里构造酉矩阵或验证等价。

### 2.2 配对薛定谔桥（I²SB 形式）

设参考过程加噪率为 \(\beta_t\)，定义累积方差：

\[
\sigma_{\text{fwd}}(t)^2 = \int_0^t \beta_\tau\, d\tau, \qquad \sigma_{\text{bwd}}(t)^2 = \int_t^1 \beta_\tau\, d\tau
\]

插值权重：

\[
\alpha_t = \frac{\sigma_{\text{bwd}}(t)^2}{\sigma_{\text{fwd}}(t)^2 + \sigma_{\text{bwd}}(t)^2}
\]

给定端点对 \((x_0, x_1)\)，任意中间态分布有闭式解：

\[
x_t \sim \mathcal{N}(\mu_t,\ \sigma_t^2 I), \qquad \mu_t = \alpha_t x_0 + (1-\alpha_t) x_1, \qquad \sigma_t^2 = \alpha_t \sigma_{\text{fwd}}(t)^2
\]

训练损失为预测噪声的均方误差：

\[
\mathcal{L}(\theta) = \mathbb{E}_{t, (x_0,x_1), x_t}\left[ \left\lVert \epsilon_\theta(x_t, t) - \frac{x_t - x_0}{\sigma_{\text{fwd}}(t)} \right\rVert_2^2 \right]
\]

BOPS 引入条件：去噪器改为 \(\epsilon_\theta(x_t, t, x_1)\)，将源 \(x_1\) 沿通道轴与 \(x_t\) 拼接（通道数由 \(c\) 变为 \(2c\)）。

### 2.3 生成（采样）

- 从 \(t=1\)（即源电路）向 \(t=0\) 反向采样；去噪器输出转化为对优化电路的估计：

\[
\hat{x}_0 = x_t - \sigma_{\text{fwd}}(t)\, \epsilon_\theta(x_t, t, x_1)
\]

- 下一步状态从桥后验采样：

\[
x_s \sim \mathcal{N}\!\left( \lambda \hat{x}_0 + (1-\lambda) x_t,\ \lambda\, \sigma_{\text{fwd}}(s)^2 I \right), \qquad \lambda = 1 - \frac{\sigma_{\text{fwd}}(s)^2}{\sigma_{\text{fwd}}(t)^2}
\]

- 训练时 \(t\) 离散为 256 步，采样时子采样为 128 步（\(\eta = 1\)）。每个源电路抽样 **64 个候选**，按门数排序后逐个验证，接受首个精确等价者。

### 2.4 电路表示

- 采用 Fürrutter 等人的张量表示：形状 \(Q \times D \times c\)，其中 \(Q\) 为比特数、\(D\) 为时间步、\(c=9\) 通道。每个 token（6 种门 + 空 + CX 控制/目标）对应一个零均值单位方差的固定正交向量，解码取余弦相似度最高者。CX 需在**同一列**中恰好有一个控制和一个目标才能解出合法电路。

### 2.5 定制去噪器（电路感知 U-DiT）

基于 U-DiT 的三项关键改造：

- **仅沿时间轴下采样**：\([B, Q, D, C_\ell] \to [B, Q, D/2, 2C_\ell]\)，从不合并行（比特轴），因为比特顺序是任意的、CX 可连接任意行。层级通道宽度为 192, 256, 384, 512, 768；\(Q\) 因此保持自由维度，使 16 比特模型可通过微调获得。
- **置换等变与比特身份表**：网络本身不读取行索引，因此加入每层学习的 64 行身份表（深层表零初始化），并用训练数据中附加的比特置换让网络「学会」等变性。
- **分组注意力**：将 \(D_\ell\) 列分为 \(f = D_\ell / g\) 组，每 token 只注意本组内 \(gQ\) 个 token，注意力代价随 \(D\) 线性而非二次增长。连续块交替使用连续窗口与交错切分。使用 RoPE 以**绝对时间步**编码位置（索引 \(j \cdot 2^\ell\)），使裁剪网格仍是完整网格的前缀。
- **规模**：40 个 block、98.8M 参数；8×512 网格一次前向约 113 GFLOP，最细层级 block 占 34% 计算量。

### 2.6 训练数据构造

- **反向生成**：先随机采样小电路 → 用规则集化简得到目标 \(C_o\) → 反复**反向应用重写规则**（部分嵌套）得到源 \(C_s\)。因规则预先验证，配对天然等价，无需构造酉矩阵。
  - 扩展规则集 86 条（36 手写 + 50 SAT 挖掘），平均加 3.9 门；化简规则集 2,763 条。
  - 允许门在不相交比特上「滑动」最多 8 位，以分散插入的结构。
- **七种数据生成过程**（在 q8t64 训练集中的占比）：atomic 5.9%、few 17.9%、medium 20.4%、hard 19.3%、chain 22.9%、natural 9.0%、Clifford 4.6%。
- **数据集规模**：
  - `q8t64`：1,953,433 训练对，验证/测试各 3,656 对；源平均 41.9 门 / 24.9 列，目标平均 18.0 门。
  - `q8t512`：8×512 网格，支持 200 次反向重写，测试源平均 164 门。
  - `q16t192`：1,097,747 训练对，省略 natural 过程。

### 2.7 等价性验证（推理期）

- 定义 \(W = U(C)^\dagger U(C')\)，\(\tau = \mathrm{Tr}(W)/2^Q\)，等价当且仅当 \(|\tau| = 1\)，过程失真为 \(1 - |\tau|^2\)。
- \(Q \le 10\)：直接构造矩阵精确判定。
- \(Q = 16\)：分层流水线（PyZX 化简 → 闭合图求 \(\mathrm{Tr}(W)\) → 无法判定则记为 undecided），无法判定的候选不被接受，因此 16 比特结果是**下界**。
- 所有报告的 BOPS 输出都经过精确验证；无通过验证者则返回源电路。

## 6. 主要结论与发现

- **优化质量**：在 q8t64 留出集（\(n = 2{,}686\)）上，BOPS（windowed）门数减少 **2.46×**、深度减少 **2.45×**，improved 达 96.5%，gap closed 95.2%，target reached 77.2%（QUESO 仅 26.1%），超越全部九个基线。
- **泛化性**：在训练分布之外的 benchmark 电路上，BOPS 缩短了 68 个 8×64 电路中的 46 个，门数 1.13×、深度 1.08×，落在基线区间内（深度上与最优基线持平），说明学习到的优化可迁移。
- **去噪器架构至关重要**：标准扩散 U-Net 仅改进 40.6% 的电路，原版 U-DiT 为 76.2%，定制版 BOPS U-DiT 达 88.9%，且步率是 U-DiT 的 1.6 倍。
- **可缩放性**：通过 50,000 步微调（7 GPU 小时，仅为原训练 45 小时的 1/6），16×64 达 89.3% improved；进一步微调到 16×192 达 72.0%（whole）/ 98.4%（windowed）。
- **主要局限**：超出注意力跨度的长电路上 whole-circuit 模式失效（257–512 时间步仅 1.1% improved）；windowed 模式虽把 improved 提到 88.7%，但会把无法缩短的窗口原样保留，导致在长电路上仅 1.23× 缩减，远低于 PyZX-fr 的 18.0×。
- **成本权衡**：BOPS 推理 4.8 s（8×64）到 40.3 s（8×512 windowed），远高于模式匹配类优化器的 0.03–0.10 s，但与 QUESO（5.09 s）/GUOQ（4.17 s）同量级；额外延迟换来的是更深的优化可达性，且候选相互独立，可并行扩展预算。

## 7. 优点

- **范式创新**：首次将源条件薛定谔桥用于电路优化，把扩散合成转化为「有紧凑输入、有验证输出」的编译器 pass；等价性编码在数据中，训练循环既不需要构造酉矩阵也不需要等价检查。
- **数据构造巧妙**：通过反向应用已验证的重写规则生成精确配对，并以不同过程（atomic/few/medium/hard/chain/natural/Clifford）显式控制重写次数、嵌套深度、电路长度与门类，构造了「对现有优化器困难」的数据分布。
- **架构适配到位**：仅沿时间轴下采样、比特身份表 + 置换等变、分组注意力、绝对时间步 RoPE —— 每一项都针对电路网格的非对称性（比特顺序无意义、CX 跨任意行、宽度需可变）而设计，并有消融实验支撑。
- **严格的正确性纪律**：所有报告输出经精确验证；无法判定者不计入成功；16 比特结果明确标注为下界；错误率数据（Qiskit 0.2%、GUOQ 0.5% 非等价）也被记录。
- **工程可复现性**：开源 `qcopt` 包，给出训练/评估/bench 命令、全部基线配置（版本号、参数、种子）、重写规则目录、复杂度证明与 GPU 内存占用。

## 8. 不足与局限

- **训练分布偏差**：训练数据由反向重写规则构造，源电路是「被人工膨胀」的电路，与真实编译器前端产生的电路结构不同。作者自己也承认，要达到 SOTA 泛化性能可能需要训练更接近 benchmark 结构的源电路。在 benchmark 上 BOPS 只与基线打平而非领先。
- **长电路限制**：whole-circuit 模式受注意力跨度约束，超过后 improvement 断崖式下降；windowed 模式以「保留未优化窗口」为代价换取正确性，导致长电路上的缩减远逊于 PyZX 系列。
